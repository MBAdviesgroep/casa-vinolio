# CASA VINOLIO

Conceptwebsite voor CASA VINOLIO van Juup Biesboer.

## Opbouw

- `index.html` — homepage, assortiment, over Juup, contact en 18+-leeftijdscontrole.
- `assets/hero.jpg` — grote homepage-foto (nog toevoegen).
- `assets/juup.jpg` — portretfoto van Juup (nog toevoegen).
- `assets/logo.png` — officiële CASA VINOLIO-logo (nog toevoegen).

De site gebruikt geen buildproces, server of database. **Vercel** kan deze repository rechtstreeks als statische website publiceren met Framework Preset **Other** en Output Directory `.`.

## Status

**Concept. Nog niet gepubliceerd.** Afbeeldingen zijn nog niet naar GitHub geüpload; voeg de drie bestanden uit het meegeleverde mediapakket toe onder `assets/` voordat je Vercel koppelt. Producten, beschikbaarheid en juridische teksten moeten vóór commerciële ingebruikname worden gecontroleerd.

## Leeftijdscontrole

Er is een 18+-toegangsvraag in JavaScript en een zichtbare NIX18-tekstuele verwijzing. Dit is geen identiteits- of leeftijdsverificatie; bij verkoop en aflevering van alcohol gelden aanvullende wettelijke verplichtingen. Vervang de gestileerde tekstbadge desgewenst door officieel NIX18-materiaal volgens de gebruiksvoorwaarden.

## Werkwijze

Wijzigingen via GitHub worden na het koppelen aan Vercel automatisch zichtbaar in de testomgeving.
